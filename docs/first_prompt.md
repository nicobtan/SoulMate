# ハイブリッド型デスクトップマスコット開発プロンプト

## 概要

Pythonをバックエンドとし、OS操作や将来的なAI機能の拡張を担わせる。フロントエンドにはWeb技術（HTML, CSS, TypeScript）とLive2Dを採用し、キャラクターの豊かな表現力とUIの柔軟性を両立させる。これらを`pywebview`のようなライブラリで結合し、一つのデスクトップアプリケーションとして機能させる「ハイブリッド型デスクトップマスコット」のプロトタイプを開発する。

## 目標

- デスクトップ上にLive2Dで描画されたキャラクターを表示する。
- ウィンドウは背景を透過し、キャラクターだけがデスクトップにいるように見せる。
- ウィンドウは常に最前面に表示され、ドラッグ＆ドロップで任意の位置に移動できる。
- キャラクターを右クリックすると、カスタムコンテキストメニューが表示される。
- コンテキストメニューから、少なくとも「アプリケーションの終了」操作ができる。

## 技術要件

- **バックエンド:** Python 3.x
- **フロントエンド:** HTML5, CSS3, TypeScript
- **キャラクター描画:** Live2D Cubism SDK for Web(一旦PNG画像で描画する)
- **ブリッジ:** `pywebview` またはそれに類するPythonからWebViewを操作できるライブラリ
- **OS:** Windows (初期ターゲット)

## 開発ステップ案

1.  **環境構築:** Pythonと`pywebview`をインストールし、基本的なウィンドウアプリケーションが起動できることを確認する。
2.  **ウィンドウ設定:** `pywebview`で生成するウィンドウを「透明」「最前面表示」「フレームレス」に設定する。
3.  **Webコンテンツ表示:** 簡単なHTMLファイルを作成し、WebView内に表示する。
4.  **Live2Dの統合:** Live2D Cubism SDK for Webを利用し、サンプルモデルをHTMLのCanvas上に描画する。
5.  **ウィンドウ操作:** TypeScriptを用いて、ウィンドウ（実際にはHTMLの`<body>`要素など）のドラッグ移動を実装する。
6.  **コンテキストメニュー:**
    -   TypeScriptで右クリックイベントをキャンセルし、独自のHTML/CSS製カスタムメニューを表示する。
    -   メニュー項目のクリックイベントを捕捉する。
7.  **Python連携:**
    -   `pywebview`のAPIを介して、TypeScriptからPythonの関数を呼び出せるようにする。
    -   「終了」メニューがクリックされたら、TypeScriptからPythonの「アプリ終了」関数を呼び出し、アプリケーションを正常に終了させる。

## 期待するプロトタイプの挙動

- 実行すると、デスクトップにLive2Dキャラクターが表示される。
- キャラクターはマウスで掴んでデスクトップ上を自由に動かせる。
- キャラクターを右クリックするとメニューが現れ、「終了」を選ぶとアプリケーションが閉じる。
