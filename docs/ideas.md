# 💡 アイデア & 将来の展望 (Ideas & Roadmap)

## 🚀 未実装 / 次のステップ (Next Steps)

### 1. Vision機能の強化 (Vision Upgrade)
- **現状**: 
  - スクリーンショットやクリップボードの画像をAIに渡す機能はあるが、基本的な実装にとどまっている。
- **アイデア**: 
  - 「画面を見て」という指示で能動的にスクショを撮り、状況を判断する機能。
  - 特定のウィンドウやアプリケーションを監視し、変化に反応する機能。

### 2. カレンダー連携の深化 (Calendar Integration)
- **現状**: 
  - 予定の取得・追加は可能だが、認証フローや活用が簡易的。
- **アイデア**: 
  - 「次の予定まであと何分？」といったカウントダウン通知。
  - 朝の挨拶（Good Morning）時に、今日の予定をまとめて読み上げる機能。
  - **話題の多様化**:
    - バブルや `[FORCE_TALK]` から提供される話題が固定化しないよう、カレンダーや過去の会話から多様なトピックを生成。

## 🔮 将来的なアイデア (Long-term Goals)

### 3. PC自律操作 (AI Agent / Computer Use)
- **現状**: 
  - 会話ログ等で「GUIを直接操作してブラウジングする」といった構想がある。
- **アイデア**: 
  - `PyAutoGUI` 等を活用し、AIがマウスやキーボードを操作して作業を代行する機能。

### 4. マルチペルソナ (Multi-Persona)
- **アイデア**: 
  - 性格の異なる二つのペルソナ（例: 姉妹、秘書と友達など）を同時に稼働させ、キャラ同士の掛け合いを実現する。

### 5. その他の改善案
- **ローカルTTS生成**:
  - GPUリソースが確保でき次第、ローカルで高品質な音声合成を行う（遅延削減）。
