# Mobile Support Implementation Instructions

## 目的
PC版の既存UI/UXには**一切影響を与えず**、スマートフォン（幅768px以下）からアクセスした時のみ、タッチ操作に最適化された「オーバーレイUI」に切り替えるレスポンシブ対応を行う。

## 原則
1. **PC版の保護:** 既存のCSSクラスのベーススタイルを変更しない。すべての変更は `@media screen and (max-width: 768px)` ブロック内、または `isMobile` フラグによる分岐で行うこと。
2. **オーバーレイUI:** スマホでは画面が狭いため、ウィンドウを並べるのではなく、Live2Dキャラクターを背景とし、UI（会話、設定、履歴）をその上に重ねて表示する。
