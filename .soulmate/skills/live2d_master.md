# Live2D Master Skills

本ドキュメントでは、SoulMateにおけるLive2Dキャラクタのパラメータ制御およびモーション遷移の運用定石を定義します。エージェントがLive2Dに関連する実装（TypeScript / Python 等）を行う際は、以下の原則を厳守してください。

## 1. パラメータ制御の基本原則

- **まばたき (EyeBlink) と リップシンク (LipSync)**
  - これらは自動制御（システム駆動）をベースとします。Lipsyncは音声波形(Audio)または指定されたテキストの母音や音量に同期させ、不自然な開閉を防ぐためにスムージング（Easing）を適用してください。
  - TTSがオフの状態や、再生エラーが発生した場合は明示的にLipsyncを停止し、口が開いたままにならないよう `ParamMouthOpenY` などを0にリセットする措置を入れます。
- **呼吸 (Breath)**
  - モーションファイルの再生に依存せず、常時動作するサイン波ベースのコントローラを使用して `ParamBreath` に数値を流し込み、生きている感を常に演出します。

## 2. モーション遷移と感情表現

- **状態管理と遷移 (State Transitions)**
  - `Idle` (待機状態) を基本モーションとし、アクションモーション再生後は必ずスムーズに `Idle` に戻るブレンド（フェードイン・フェードアウト時間を最低でも0.3〜0.5秒確保する）を設定します。
  - モーションキューの優先度管理に注意し、システムクリティカルなモーション（エラーモーションなど）は通常のランダムモーションより優先実行されるようにします。
- **感情パラメータの連動**
  - 単一の表情(Expression)切り替えだけでなく、頭の傾き (`ParamAngleX`, `ParamAngleY`, `ParamAngleZ`) や眉の動き (`ParamBrowLY`, `ParamBrowRY`, `ParamBrowLAngle`, `ParamBrowRAngle`) と連動させて感情を表現します。
  - 例：【悲しみ・エラー時 (＞＜)】
    - 表情(Exp): `cry` または `error`
    - パラメータ: `ParamAngleZ` をわずかに傾け、`ParamBrowLY`, `ParamBrowRY` をハの字に下げることで、困った・申し訳ないという人間らしい「包容力」ある雰囲気を出すこと。

## 3. 実装上の注意 (エラー時のフォールバック)

- モーションファイルや表情ファイル（`.exp3.json`、`.motion3.json`等）が見つからない、またはパースに失敗する例外が発生した場合には、アプリケーション全体をクラッシュさせず、デフォルトのIdleモーションと標準的な表情へとフォールバックしてください。
- ログには必ずどのファイルでパースエラーが発生したかを明記し、デバッグを容易にします。
