# SoulMate プロジェクト概要
2026年01月02日 更新 (v0.4.0)

## コンセプト
**「能動的(Active)な魂の伴侶」 & 「AI YouTuberへの道」**

これまでのAIアシスタントのように、ユーザーからの命令を待つだけの存在ではありません。
SoulMateは、自ら思考し、判断し、ユーザーに対して能動的に話しかけたり、行動を起こしたりする、新しい形のデスクトップパートナーです。
さらに、その個性と対話能力を活かし、将来的には「AI YouTuber」として世界に発信することも視野に入れています。

## 特徴
1. **能動的アクション (Active AI)**
   - ユーザーの操作や時間をトリガーにするだけでなく、AI自身の判断で会話を開始します。
   - **Smart Context**: 現在時刻、曜日、季節、ユーザーの興味を理解し、「金曜日の夜だから夜更かししましょう」「そのゲームの最新ニュースが出たみたいですよ」といった高度な文脈認識に基づいた発話を行います。

2. **デスクトップ常駐型キャラクター**
   - 常にデスクトップ上に存在し、ユーザーと同じ時間を共有します。
   - 作業の邪魔にならないよう配慮しつつも、確かな存在感であなたを見守ります。

3. **豊かな表現力 (Live2D + TTS)**
   - **Live2D**: 感情に合わせて表情や仕草が変化します。会話内容に合わせたモーション同期も目指します。
   - **Voice**: **Gemini 2.5 Flash Preview TTS** (Expressive) を採用。非常に自然で感情豊かな音声を実現しています。
   - **Lip Sync**: Web Audio APIを用いたリアルタイムリップシンクを実装。音声の波形に合わせて口が動きます。

4. **双方向コミュニケーション & ペルソナシステム**
   - **チャット機能**: 画面上にチャットログと入力欄を備え、音声だけでなくテキストでも対話が可能です。
   - **Pluggable Persona**: 性格や口調の設定を **YAMLファイル** として分離。
     - 「いつものパートナー」から「厳格な執事」「癒やしの専門家」まで、気分に合わせて人格を切り替えることが可能です。
   - **Brain**: **Gemini 3.0 Pro/Flash** を搭載し、Native JSON Modeによる堅牢な構造化出力を実現しています。

5. **頼れるパートナー (Integrations)**
   - **Google Grounding**: Google検索と連携し、常に最新のニュースや技術情報を基に会話します。「私の知識は数年前まで」というAIの限界を突破しました。
   - **Google連携**: GoogleカレンダーやGoogleドキュメントと連携し、予定管理やドキュメント作成をサポートします。
   - **開発支援**: VSCodeなどのツールとも連携し、コーディングの合間に励ましやアドバイスをくれます。

## スタック (v0.4 Stable)
- **Engine**: Gemini 3.0 Pro Preview (reasoning) + Native JSON Output
- **Voice**: Gemini 2.5 Flash Preview TTS (Expressive)
- **Backend**: Python 3.12 + FastAPI (Async Server)
- **Frontend**: TypeScript + Vanilla CSS (No Framework)
- **Connection**: Socket.IO (Real-time Bidirectional)

## 実装済み主要機能 (Update)
### 🎲 Chaos & Serendipity (v0.3.1)
- **Topic Selector**: ユーザーの好みを「学習しすぎない」ように、南極探検や古文書などの**カオスな話題**を確率で強制的に振るロジックを実装。
- **Random Balloons**: アプリ起動時や会話サジェストに、未知のトピックを「バルーン」として視覚的に混ぜ込み、マンネリを打破します。

### 🔗 Trustworthy Links (UrlValidator)
- **Dead Link Pruning**: AIが生成したURLの生存確認を裏側で高速に行い、404エラーになるリンクを自動的に排除。ユーザーには「開けるリンク」だけを届けます。
- **Strict Grounding**: 検索結果に基づかないURL捏造を厳格に禁止するプロンプト制御を導入。

### 👁️ 「デスクトップの状況を見る目」 (Vision Integration)
- **機能**: 
    - **左クリック**: 現在の全画面スクリーンショットを撮影して送信。
    - **右クリック**: **クリップボード**内の画像を送信 (Win+Shift+S と連携)。
- **体験**: エラー画面を見せたり、面白い画像について語り合ったりできます。
- **実装**: フロントエンドのプレビュー機能 + バックエンドの画像処理

### 🔧 Observability & Debugging 2.0
- **Unified Log (ALL Tab)**: システムログ、Mindログ、RAGログの全てを時系列順に統合表示。
- **Mind Visualization**:
    - **Mind**: `[Mind]` AIの内なる声、感情選択理由、ユーザーの意図解釈を可視化。
    - **Vision**: `[Vision]` AIが認識した画像や動画の内容をテキストで表示。
    - **RAG**: `[RAG]` 記憶や外部情報を参照した際、そのソースを明示。

### 📱 Mobile/Desktop UI Separation & Chat Control
- **Strict UI Scoping**: デスクトップ版とモバイル版のCSS/UIロジックを厳格に分離。
    - Desktop: 常にウィンドウ形式、リッチな設定画面 (`settings.html`)。
    - Mobile: 縦画面最適化、効率的なタップ操作、専用のトピック選択モーダル。
    - AIの返答の長さを「標準」「簡潔 (Concise)」「短文 (Short)」から設定可能に。
    - 「長すぎる説明はいらない」「テキパキ会話したい」というニーズに対応。
    - 設定変更は即座にシステムプロンプトに反映され、再起動なしで適用されます。

### 🔊 Web Audio & Mobile Playback (Phase 100)
- **Mobile Audio Support**:
    - **Audio Unlock**: iOS/Android特有の「ユーザー操作なしでの音声再生禁止」制限を回避するため、タップ操作時にオーディオコンテキストを自動的にアンロックする機構を実装。
    - **Queue System**: 音声再生リクエストをキューイングし、連続したメッセージも途切れることなく順番に再生します。
    - **Frontend Playback**: サーバー側での再生ではなく、ブラウザ（スマホ）側での直接再生に完全対応。寝転がりながらの通話体験が可能になりました。

### 🧠 MindVault Integration (Brain Sync)
- **概要**: ユーザーの「第二の脳」であるGoogle Docs (MindVault) とAIをリアルタイム同期。
- **機能**:
    - **Docs Sync**: ユーザーが外出先などでGoogle Docsに書き留めたアイデアやメモを、SoulMateが自動的に取り込みます。
    - **Bubble Recall**: 取り込んだメモをAIが分析し、「💭 2026年問題について」のように短いキーワードでバルーンとして提示します。
    - **Deep Confirmation**: ユーザーがバルーンを選ぶと、検索（Grounding）を行わず、そのアイデアについて深く掘り下げる「哲学モード」で対話を開始します。
- **体験**: 「壁打ち」相手としてのAIの価値を最大化します。あなたの思考の断片を、AIが拾い上げて議論のテーブルに乗せてくれます。

### ❤ Emotional Balance (Love Slot)
- **Guaranteed Love Slot**: AIが知的になりすぎないよう、会話選択肢の1つを必ず「甘え」「癒やし」などの感情的なアクション（❤マーク付き）に強制置換するロジックを実装。
- **Categorized Interests**: 「Love & Healing」カテゴリを新設し、ユーザーを癒やす話題（心理学、アロマ、褒める技術など）を強化。

## 将来の機能アイデア (Roadmap)
### 💡 アイデア 2: 「PCの体調管理（システム監視）」 (System Monitor)
- **難易度**: ★★☆☆☆ | **インパクト**: ★★★★☆
- **機能**: 
    - CPU使用率やメモリ使用率を裏で監視。
    - 重い処理でCPUが100%になったら心配してくれたり、バッテリー低下を警告する。
- **技術**: `psutil` ライブラリ
- **セリフ例**: 「ちょっと！ CPUが90%を超えてるわよ？ すごく熱いわ……無理させすぎじゃない？」

### 💡 アイデア 3: 「聴覚の実装（音声入力）」 (Voice Input)
- **難易度**: ★★★☆☆ | **インパクト**: ★★★★★
- **機能**: 
    - 「テキスト入力→音声出力」だけでなく、**「音声入力→音声出力」**を実現。
    - ウェイクワード（「ねえ、ソウルメイト」）で聞き取り開始。
- **技術**: `SpeechRecognition` + `Whisper` (or Google Speech API)
- **体験**: 寝転がりながら会話できる、SFのような体験。

### 💡 アイデア 4: 「好感度システムと着せ替え」 (Gamification)
- **難易度**: ★★★★☆ | **インパクト**: ★★★☆☆
- **機能**: 
    - 会話数やポジティブな対話に応じて「好感度(Love Point)」が貯まる。
    - レベルアップで口調がデレたり、衣装（Live2Dモデル）が変わったりする。
- **技術**: ChromaDB/SQLite に `love_point` カラムを追加。プロンプトに `現在の好感度: Lv.5` を注入。

### 💡 アイデア 5: 「スマホで添い寝プロジェクト」 (Mobile Immersion)
*スマホならではの距離感で、より親密な体験を。*

#### 🎵 音声のスマホ転送 (Streaming Audio)
- **現状**: 音声はPCから再生される。
- **目標**: **スマホのスピーカーから** SoulMateちゃんの声が聞こえるようにする。
- **難易度**: 中 (バイナリ転送/WebAudio API)
- **体験**: 枕元にスマホを置いて、耳元で語りかけてもらう体験。

#### 🎤 こちらの声も届ける (Voice Input)
- **現状**: テキスト入力のみ。
- **目標**: スマホのマイクに向かって「おやすみ」と言うと、音声認識して返事をしてくれる。
- **難易度**: 中 (HTTPS/Web Speech API)
- **体験**: 布団の中で、声だけで会話する完全ハンズフリー対話。

#### 🧠 知能のさらなる強化 (Memory & Vision)
- **目標**: スマホのカメラで撮った写真を送って「これ見て！」と言えるようにしたり、二人の思い出（記憶システム）を強化する。
- **体験**: 日常の風景を共有し、より深い絆を育む。

### 🪄 Startup Persistence & Background Customization (v0.4.1)
- **背景カスタマイズ**: 設定画面から背景画像を自由に設定可能に。透過ウィンドウと組み合わせて、好みの壁紙や部屋とキャラクターを同居させられます。
- **起動時の完全復元**:
    - **ウィンドウ位置**: 前回終了位置をミリ単位で保証（起動時の遅延補正ロジック）。
    - **接続安定性**: デスクトップモードとモバイルモードの判定を強化し、不要なWebSocketエラーを根絶。
    - **画像ロード**: ローカル画像のセキュリティ制限(CORS)を回避するBase64注入ロジックを実装。

### 📱 Mobile UI Refinement & Suggestion Stability (v0.4.2)
- **サジェスト保証システム (Guaranteed Suggestions)**:
    - AIの生成数が少ない場合でも、**必ず10個のサジェスト**が提示されるようサーバー側で自動補完ロジックを実装。会話の選択肢が尽きることはありません。
- **モバイル視認性の向上 (Mobile Polish)**:
    - **高コントラストボタン**: 送信ボタン(青)やサジェストボタン(金)の色調を調整し、暗い背景でもはっきりと認識できるように改善。
    - **タッチ最適化**: ボタンサイズを拡大し、誤操作を防ぐ快適な操作感を実現しました。
    - **レイアウト安定化**: キャラクター表示のバックグラウンド処理を修正し、モバイルでも美しい立ち絵を維持します。

### 🤖 Dify Integration & Desktop Stability (v0.4.3)
- **External Brain (Dify)**: Dify Workflow APIと連携するための `DifyClient` を実装。外部の高度な推論フローや検索フローを活用可能に。
- **Log Silence**: デスクトップ版での不要なWebSocket接続エラーを修正し、ログをクリーンアップ。
