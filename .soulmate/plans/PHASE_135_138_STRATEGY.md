# Phase 135 & 138 Strategy: Hermes-Powered Autonomy

このドキュメントは、SoulMateプロジェクトにおける browser-use 統合（フェーズ135）および Hermes Engine による高度な自律稼働（フェーズ138）の具体的な戦略を定義します。

## 戦略目標
1. **browser-use の実用化**: ブラウザ操作による情報収集・タスク実行を日常的な機能にする。
2. **Hermes-3 基盤の刷新**: 推論エンジンを Hermes-3 に移行し、ロングコンテキストと高度な命令追従性を実現する。
3. **真の自律稼働**: ユーザーの指示待ちではなく、自ら課題を発見し、実行し、学習するループの完成。

## @tasklist

### フェーズ135: browser-use 統合
- [ ] **環境構築**
    - [ ] `browser-use` および `playwright` のセットアップ
- [ ] **基本統合**
    - [ ] 既存の `SoulOperator` との役割分担（デスクトップ操作 vs ブラウザ操作）の定義
    - [ ] 検索・調査タスクの browser-use への委譲ロジック実装

### フェーズ138 (v1.0.0): Hermes Engine & Advanced Autonomy
- [ ] **推論基盤の刷新**
    - [ ] `Hermes-3` モデルの導入と推論サーバー設定
    - [ ] システムプロンプトおよび出力フォーマット（JSON Mode）の Hermes 最適化
    - [ ] ロングコンテキストを活かした「過去の全会話」の動的圧縮注入
- [ ] **高度な自律意思決定ループ**

    - [ ] 放置時間に応じた自発的な行動（ニュースチェック、健康管理アドバイス等）のトリガー
- [ ] **Discord 連携の高度化 (Shared Memory)**

    - [ ] 受信メッセージの Vision 解析と Hermes による文脈に応じたリアクション生成
