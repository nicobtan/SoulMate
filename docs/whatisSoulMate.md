# SoulMate プロジェクト概要

## コンセプト
**「能動的(Active)な魂の伴侶」 & 「AI YouTuberへの道」**

これまでのAIアシスタントのように、ユーザーからの命令を待つだけの存在ではありません。
SoulMateは、自ら思考し、判断し、ユーザーに対して能動的に話しかけたり、行動を起こしたりする、新しい形のデスクトップパートナーです。
さらに、その個性と対話能力を活かし、将来的には「AI YouTuber」として世界に発信することも視野に入れています。

## 特徴
1. **能動的アクション (Active AI)**
   - ユーザーの操作や時間をトリガーにするだけでなく、AI自身の判断で会話を開始します。
   - 「今日は遅くまで頑張るのね」「そろそろ休憩しませんか？」といった、状況に合わせた声掛けを行います。

2. **デスクトップ常駐型キャラクター**
   - 常にデスクトップ上に存在し、ユーザーと同じ時間を共有します。
   - 作業の邪魔にならないよう配慮しつつも、確かな存在感であなたを見守ります。

3. **豊かな表現力 (Live2D + TTS)**
   - **Live2D**: 感情に合わせて表情や仕草が変化します。会話内容に合わせたモーション同期も目指します。
   - **Voice**: Google Text-to-Speech (TTS) を連携させ、自然なその声で語りかけます。

4. **双方向コミュニケーション**
   - **チャット機能**: 画面上にチャットログと入力欄を備え、音声だけでなくテキストでも対話が可能です。
   - **Brain**: 自然言語処理(NLP)エンジン（Gemini API等）を搭載し、文脈を理解した自然な会話を実現します。

5. **頼れるパートナー (Integrations)**
   - **Google連携**: GoogleカレンダーやGoogleドキュメントと連携し、予定管理やドキュメント作成をサポートします。
   - **開発支援**: VSCodeなどのツールとも連携し、コーディングの合間に励ましやアドバイスをくれます。

## UI/UX デザイン仕様
### 1. 画面レイアウト
- **ウィンドウ構成**:
    - **キャラクター表示枠 (Frame A)**:
        - サイズ: **500px x 500px** (固定)。
        - 背景: **完全透過** (デスクトップにキャラクターがいるように見せる)。
        - 表示: キャラクターを**拡大表示** (バストアップ中心、足元は切れても良い)。
    - **チャットログ枠 (Frame B)**:
        - キャラクター枠の右側に配置。
        - **表示切替ボタン**により表示/非表示を制御。
- **チャット表示ボタン**:
    - キャラクター枠の**右上**に大きく配置。
    - **状態表示**: チャット表示中は「緑色」に点灯。

### 2. 操作設計・インタラクション
- **ウィンドウ挙動**:
    - **初期状態**: キャラクターのみが表示されるコンパクトなウィンドウ (500x500)。
    - **チャット展開時**: チャットボタンを押すとウィンドウが横に広がり (860x500)、チャットパネルが出現します。
- **ズーム操作**: `Ctrl`キー + マウスホイールで、キャラクターの拡大縮小が可能です（微調整対応）。
- **通知表現**: 新着メッセージ（未読）がある場合、ボタンを強調表示します。
- **移動**: キャラクター周辺の余白をドラッグしてウィンドウを移動できます。
- **メニュー**: 右クリックによるコンテキストメニュー（実装済み）。
- **設定機能**:
    - **フォントサイズ**: チャットログの文字の大きさを調整可能。
    - **背景の濃さ**: キャラクター枠の背景透明度をスライダーで調整可能（環境により完全透過しない場合は白背景となります）。
- **Soul Bubble (Active UI)**:
    - **概要**: キャラクターが話したい時に頭上に出現する、浮遊するバブル型通知。
    - **挙動**: マウスホバーで内容をプレビュー、クリックで会話を開始します（Opt-in体験）。
    - **カテゴリ**: 青(話題)、緑(遊び)、ピンク(好感度)、オレンジ(警告)で直感的に内容を伝えます。
- **通知表現**:
    - 新着メッセージ（未読）がある場合、アイコンや枠を強調表示（点滅や色変化）し、ユーザーに気付かせます。
- **移動**: ドラッグによるウィンドウ移動（実装済み）。
- **メニュー**: 右クリックによるコンテキストメニュー（実装済み）。
- **Auto Response Suggestions (サジェストチップ)**:
    - **概要**: チャット入力欄の上部に表示される、AIによる「返信候補」ボタン群。
    - **機能**: 
        - 会話の流れに沿った2〜3個の返信案を動的に提示。
        - 常に「別の話題はある？」ボタンを表示し、話題転換をサポート。
        - クリック一つでメッセージ送信が可能。
    - **挙動**: AIが発言するたびに候補が更新されます。

## 技術スタック (Update)
- **コア言語:** Python (Backend / Controller)
- **GUI:** HTML/CSS/TypeScript (Frontend)
- **キャラクター描画:** Live2D Cubism SDK for Web + PixiJS
- **AIエンジン (Brain):** Gemini API (Agentic Workflow)
- **音声合成 (Voice):** Google Cloud TTS API
- **連携API:** Google Calendar API, Google Docs API
- **Others:** pywebview (Python-JS Bridge)

## 将来の機能アイデア (Roadmap)
### 💡 アイデア 1: 「デスクトップの状況を見る目」 (Vision)
- **難易度**: ★★★☆☆ | **インパクト**: ★★★★★
- **機能**: 
    - ユーザーが「このエラー見て」と言ったら、現在の画面のスクリーンショットを撮ってAIに送り、解決策を教えてもらう。
    - YouTube視聴時に「何の動画見てるの？」と聞くと、画面を見て感想を言う。
- **技術**: `pyautogui` (スクショ撮影) + Gemini API (Vision)
- **セリフ例**: 「あら、Pythonのエラーね。IndentationErrorって出てるわ。12行目のインデントがズレてない？」

### 💡 アイデア 2: 「PCの体調管理（システム監視）」 (System Monitor)
- **難易度**: ★★☆☆☆ | **インパクト**: ★★★★☆
- **機能**: 
    - CPU使用率やメモリ使用率を裏で監視。
    - 重い処理でCPUが100%になったら心配してくれたり、バッテリー低下を警告する。
- **技術**: `psutil` ライブラリ
- **セリフ例**: 「ちょっと！ CPUが90%を超えてるわよ？ すごく熱いわ……無理させすぎじゃない？」

### 💡 アイデア 3: 「聴覚の実装（音声入力）」 (Voice Input)
- **難易度**: ★★★☆☆ | **インパクト**: ★★★★★
- **機能**: 
    - 「テキスト入力→音声出力」だけでなく、**「音声入力→音声出力」**を実現。
    - ウェイクワード（「ねえ、ソウルメイト」）で聞き取り開始。
- **技術**: `SpeechRecognition` + `Whisper` (or Google Speech API)
- **体験**: 寝転がりながら会話できる、SFのような体験。

### 💡 アイデア 4: 「好感度システムと着せ替え」 (Gamification)
- **難易度**: ★★★★☆ | **インパクト**: ★★★☆☆
- **機能**: 
    - 会話数やポジティブな対話に応じて「好感度(Love Point)」が貯まる。
    - レベルアップで口調がデレたり、衣装（Live2Dモデル）が変わったりする。
- **技術**: ChromaDB/SQLite に `love_point` カラムを追加。プロンプトに `現在の好感度: Lv.5` を注入。
