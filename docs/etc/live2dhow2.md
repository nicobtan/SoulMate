# 1枚絵からLive2Dモデルを作成する方法（初心者向け推奨ワークフロー）

このガイドは、専門的な知識がない初心者でも、1枚のイラストからLive2Dモデルを作成するための現代的な手順をまとめたものです。
AI技術を活用することで、従来は非常に手間がかかった「パーツ分け」作業を自動化し、Live2Dの強力なテンプレート機能を組み合わせることで、効率的にモデルを作成します。

## ワークフローの概要

1.  **イラストの準備**: 動かしたいキャラクターのイラストを1枚用意します。
2.  **AIによるパーツ分け**: AIツールを使って、イラストをLive2Dで動かすために必要なパーツ（髪、顔、目、口など）に自動で分割します。
3.  **Live2D Cubism Editorでのモデル作成**: 分割されたパーツをLive2D Cubism Editorに読み込み、テンプレート機能を適用して自動で動きをつけます。
4.  **モデルのエクスポート**: 完成したモデルを、VTube Studioなどのアプリケーションで使える形式（`.moc3`）で書き出します。

---

## ステップ1：AIによるパーツ分け

従来、手作業で数時間〜数日かかっていたパーツ分けを、AIで自動化します。

1.  **ツールの準備**:
    *   **LayerDivider** のようなツールを探します。これは、画像分割AI「Segment Anything Model (SAM)」を利用して、イラストを自動でレイヤー分けしてくれるツールです。
    *   検索キーワード: `LayerDivider AI`, `SAM image splitter`
    *   *（補足: これらのツールは有志によって開発されていることが多く、セットアップにPCの知識が多少必要になる場合があります。）*

2.  **実行**:
    *   ツールを起動し、用意した1枚絵を読み込ませます。
    *   AIがキャラクターの各部分を認識し、それぞれをレイヤーに分けたPSDファイル（Photoshop形式ファイル）として出力します。この時、AIは元々描かれていなかった隠れた部分（例：髪の裏側）もある程度補完して生成してくれます。

## ステップ2：Live2D Cubism Editorでの作業

AIが生成したPSDファイルを使って、Live2Dモデルを組み立てます。

1.  **Live2D Cubism Editorのインストール**:
    *   公式サイトからCubism Editorをダウンロードしてインストールします。無料で使用できるFREE版と、高機能なPRO版（42日間の試用期間あり）があります。テンプレート機能はPRO版の機能ですが、試用期間中に利用できます。
    *   **ダウンロードURL**: [https://www.live2d.com/download/cubism/](https://www.live2d.com/download/cubism/)

2.  **PSDファイルの読み込み**:
    *   Cubism Editorを起動し、ステップ1で作成したPSDファイルをドラッグ＆ドロップで読み込みます。

3.  **テンプレート機能の適用**:
    *   上部メニューの `ファイル` > `テンプレートを適用` を選択します。
    *   プレビューが表示されるので、キャラクターの顔や体の位置がテンプレートのガイドに合うように、マウスで調整します。
    *   適用ボタンを押すと、呼吸、顔の向き（X, Y, Z）、目の開閉、口の開閉などの基本的なパラメータが自動で設定されます。

## ステップ3：モデルのエクスポート

1.  **動作の確認**:
    *   画面上でドラッグして、モデルが顔の向きに合わせて動くか確認します。自動で設定された動きが、キャラクターに自然に反映されているはずです。

2.  **モデルの書き出し**:
    *   上部メニューの `ファイル` > `組込み用ファイル書き出し` > `moc3ファイル書き出し` を選択します。
    *   表示された設定画面でOKを押し、モデルを書き出します。これにより、Live2Dモデルの本体である `.moc3` ファイルや、設定ファイルなどが一式生成されます。

## 完成

以上で、1枚のイラストからLive2Dモデルが完成しました。
書き出したファイル群は、VTube Studioなどの対応アプリケーションに導入することで、ウェブカメラと連動して動かすことができます。
